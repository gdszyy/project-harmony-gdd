# Project Harmony 特效需求分析文档

**作者：** gdd_analyst (Manus AI)
**日期：** 2026-03-06
**版本：** 2.0

## 1. 概述

本文档基于对 `Project Harmony` 项目设计文档（GDD）及相关子系统文档的深入分析，从特效（VFX）设计的角度梳理了项目的核心需求。项目采用“抽象矢量主义 vs. 数字衰变”的双极美学体系，特效设计不仅是视觉包装，更是核心玩法（音乐战斗融合、共鸣切割、听感疲劳等）的直接视觉反馈。

## 2. 核心系统特效需求清单

### 2.1. 音符法术系统 (Spell System)

法术系统是玩家输出的核心，其特效需要清晰传达法术的层级、属性和状态。基础弹体（层级 1.5）需要基于四维参数（DMG, SPD, DUR, SIZE）进行程序化视觉分化。例如，E音符作为巨型缓行弹体，表现为大范围半透明能量球并带有厚重拖尾；G音符作为高伤快消弹体，表现为细小高亮能量奇点并带有极亮短拖尾；D音符作为极速远程弹体，表现为细长光矢。这些差异应通过Shader参数调整亮度、透明度、拖尾长度来实现，避免过度使用特殊机制视觉语言。

黑键修饰符（层级 1）需要提供瞬时、清晰的预示性特效。穿透效果表现为青色激光指示器和锐利光刃；追踪效果表现为蓝色动态准星和数据流；分裂效果表现为不稳定能量核心和电弧；回响效果表现为半透明鬼影延迟；散射效果表现为扇形虚拟弹道。

和弦法术（层级 2）引入了全新的视觉语言，体现了法术形态的“质变”。

| 和弦类型 | 法术形态 | 核心视觉表现 |
| :--- | :--- | :--- |
| 大三和弦 | 强化弹体 | 圣光金强化弹体，表面有稳定、明亮的六边形能量网格流动 |
| 小三和弦 | DOT弹体 | 暗蓝色液体质感，表面有缓慢旋转的漩涡，附带腐蚀效果 |
| 增三和弦 | 爆炸弹体 | 烈焰橙爆炸弹体，呼吸胀缩，命中产生剧烈范围爆炸 |
| 减三和弦 | 冲击波 | 深紫色环形冲击波，波前是锋利能量刀刃，波后是扭曲空间涟漪 |
| 属七和弦 | 法阵/区域 | Dominant黄几何法阵（如六芒星），边缘有上升能量粒子 |
| 减七和弦 | 天降打击 | 血红色预警区域，光柱落下瞬间全屏闪白，强烈屏幕震动 |
| 大七和弦 | 护盾/治疗 | 治愈绿半透明半球形护盾，表面有蜂巢状能量格流动 |
| 小七和弦 | 召唤/构造 | 深蓝色水晶/金属构造体，具有模块化拼接动画 |
| 挂留和弦 | 蓄力弹体 | 银白色蓄力能量球，周围空间扭曲，能量线被吸入球体 |

节奏型修饰（层级 4）改变了弹体的运动轨迹和发射模式。连射表现为密集弹幕流；重击表现为体积增大、颜色加深和夸张击退；闪避射击表现为玩家向后残影位移；摇摆弹道表现为正弦曲线拖尾；三连发表现为扇形发射；精准蓄力表现为休止符位置的能量漩涡吸入。

和弦进行组合效果（层级 5）为高阶操作提供强烈的正向反馈，通常以全屏特效的形式出现。D→T进行产生全屏金色冲击波和暖色调染色；T→D进行产生屏幕边缘琥珀色收缩和鱼眼畸变；PD→D进行产生全屏紫色加速线条，营造超空间航行感。

### 2.2. 音色战斗系统 (Timbre System)

音色系统为法术附加攻击“质感”，这些质感需要与法术的基础形态完美融合。

| 音色系别 | 视觉表现与命中反馈 |
| :--- | :--- |
| 弹拨系 | 弹体被水墨波纹或金色光珠包裹，拖尾短促有力。命中时产生同心圆冲击波。 |
| 拉弦系 | 弹体由两股缠绕能量丝线构成，拖尾为连绵光轨。命中留下共振标记并产生能量弧线连接。 |
| 吹奏系 | 弹体呈半透明气流状，前端聚焦，拖尾为气流轨迹。穿透敌人时留下竹叶或风旋粒子。 |
| 打击系 | 弹体形态规整（圆/方），拖尾为坚实冲击轨迹。强拍命中产生物理破碎感和屏幕震动。 |

### 2.3. 共鸣切割系统 (Resonance Slicing)

频谱相位切换是游戏的核心解谜机制，要求实现瞬间、彻底的全局视觉重塑。

| 相位 | 全局视觉风格 | 玩家与法术视觉变化 |
| :--- | :--- | :--- |
| 高通相位 (Overtone) | 全屏闪白过渡，明亮线框化、冷色调。物体边缘锐化，上升气泡粒子。 | 玩家核心和弹体变亮变细，拖尾变直。弹拨系视觉效果强化。 |
| 低通相位 (Sub-Bass) | 全屏闪黑过渡，暗沉液态化、暖色调。物体边缘模糊，下降岩浆粒子。 | 玩家核心和弹体变厚重庞大，颜色加深。打击系视觉效果强化。 |
| 全频相位 (Fundamental) | 平滑过渡回原始美术风格，色彩和形态恢复正常。 | 所有视觉效果恢复默认。拉弦系视觉效果强化。 |

### 2.4. 召唤系统 (Summoning System)

召唤物作为“伴奏声部”，其特效需与音频事件和节拍严格同步。节拍哨塔每拍发射弹体，伴随清脆的发射特效；长程棱镜在弹体穿过时触发延迟回声特效；低频音墙表现为持续存在的门限脉冲视觉效果；净化信标每小节触发从高到低的滤波扫频视觉波纹；重低音炮在强拍发射深沉的低频冲击波；和声光环提供持续的柔和和声铺底光环；高频陷阱表现为快速的高频节奏序列闪烁。

### 2.5. Boss战特效 (Boss Visual Effects)

Boss特效需强化其代表的时代特征和核心机制，并与节拍严格绑定。

| Boss | 时代特征 | 核心视觉表现 |
| :--- | :--- | :--- |
| 圭多 | 中世纪 | 神圣、羊皮纸、金光。圣咏力场（四线谱投影），音符飞弹（方形音符），圣咏审判（金色十字架/光柱）。 |
| 巴赫 | 巴洛克 | 精密、几何、齿轮、冷色调。对位力场（复杂几何旋转），赋格弹幕（螺旋轨迹），管风琴重击（冰蓝音波柱）。 |
| 莫扎特 | 古典主义 | 优雅、水晶、明亮。奏鸣曲式力场（大理石反光），圆舞曲弹幕（水晶质感），镜面反射（彩虹色散镜面）。 |
| 爵士 | 爵士乐 | 暧昧、霓虹、烟雾、剪影。摇摆力场（霓虹灯带闪烁），萨克斯音波（扭曲波浪），切分瞬移（紫色烟雾消散凝聚）。 |

### 2.6. 环境场景与全局视觉 (Environment & Global Visuals)

全局视觉环境由 `GlobalVisualEnvironment3D` 管理，负责 Glow、Tonemap 和章节色彩过渡，并提供节拍驱动的全局视觉脉冲（Beat Glow Boost）。章节视觉管理器 `ChapterVisualManager` 负责动态切换地面Shader（如克拉尼图形、大教堂、巴洛克几何等），并管理章节环境特效。项目采用 2.5D 渲染桥接架构，在2D逻辑上叠加3D渲染结果，从而实现原生辉光、体积雾、动态光照和3D粒子效果。

### 2.7. UI与反馈特效 (UI & Feedback)

听感疲劳系统提供了强烈的负面视觉反馈。单调寂静状态下，法术槽变得灰暗、布满裂纹并被红色交叉线划掉，战场上对应的弹体变灰消散。噪音过载会导致弹道偏移，弹体出现像素化或色块分离的故障效果。不和谐腐蚀会使血条被紫色的“数字病毒”腐蚀。频谱失调则会引发屏幕剧烈扭曲，导致音色效果失效。

法术槽交互方面，拖入法术时图标会液化流入，槽体发光。不同类型的法术槽具有材质区分（音符为水晶，和弦为金属，修饰符为电路板）。序列器背景会根据当前设定的节奏型进行动态纹理化。

## 3. 项目独特逻辑分析

### 3.1. 音乐战斗融合机制

特效的触发和表现必须与音乐节拍（BPM）严格同步。例如，全局Glow的脉冲、Boss技能的爆发、召唤物的攻击、甚至UI的闪烁，都由 `GameManager.beat_tick` 或十六分音符调度器驱动。特效不仅是视觉的，更是“可视化的节拍器”。

### 3.2. 和弦组合对特效映射

法术特效不是预设的固定资产，而是基于玩家“编曲”动态生成的。基础音符决定弹体物理属性，黑键决定修饰效果，和弦类型决定法术形态（如大三和弦对应强化弹体，减七和弦对应天降打击），和弦进行决定组合爆发效果。这要求特效系统具备高度的模块化和可组合性。

### 3.3. 音色视觉表达

音色作为“行为滤镜”叠加在法术形态之上，要求Shader能够灵活地在基础弹体上附加特定的视觉特征（如水墨波纹、能量丝线），且不能破坏基础形态的辨识度。

### 3.4. 2.5D特效空间

项目采用“2D逻辑+3D渲染桥接”架构。这意味着特效（如粒子、光照）是在独立的3D场景中渲染，然后叠加到2D画面上。特效设计师需要利用Godot 4.x的3D粒子系统（GPUParticles3D）和全屏后处理来实现高质量的视觉效果，同时确保与2D物理位置的精确同步。

### 3.5. 美学疲劳系统

疲劳系统将惩罚机制视觉化为“数字衰变”和“故障艺术”。特效需要表现出从“和谐”到“崩溃”的渐变过程，如UI的像素化、弹体的褪色、屏幕的扭曲等，这与传统的冷却时间UI表现截然不同。

## 4. 约束条件与机会点

### 4.1. 约束条件

性能约束是首要考虑的因素。大量程序化生成的弹体、复杂的Shader计算、3D粒子系统和全屏后处理，对性能要求较高。必须严格使用对象池（VFXManager）和优化的Shader代码。其次是信息清晰度，在同屏大量弹幕、特效和UI元素的情况下，必须保证核心战斗信息（敌人位置、危险弹幕、自身状态）的清晰可读，特效不能喧宾夺主。最后，视觉特效与音频节拍的同步必须极其精准，任何延迟都会破坏“通感”体验。

### 4.2. 机会点

利用Godot的程序化Shader能力，可以实现极其丰富且动态的法术形态和音色变化，减少美术资产的制作量，同时提升视觉的独特性。2.5D架构带来的3D渲染管线红利（原生辉光、动态光照和高级粒子），可以大幅提升游戏的画面表现力，使其在同类2D游戏中脱颖而出。此外，疲劳系统和敌人设计中的“噪音/故障”概念，为特效设计提供了极大的创意空间，可以创造出极具视觉冲击力和心理压迫感的独特效果。
