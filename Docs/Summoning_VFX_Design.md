## 1. 设计概述与哲学

### 1.1. 文档定位

本文档是《Project Harmony》召唤系统（幻影声部）视觉特效的**完整设计规范**，旨在将召唤系统的游戏机制逻辑转化为可感知、可读取的视觉语言。召唤物在本游戏中的核心定位是"伴奏声部"而非"独立战斗单位"，因此其视觉设计必须服务于这一核心隐喻：它们是战场上可见的"节拍器"，是玩家"指挥棒"下的"乐手"。

### 1.2. 核心设计原则

本方案在遵循《3D 游戏特效设计核心方案》中可读性、节奏感、层次感和反馈感四大原则的基础上，针对召唤系统的特殊性，确立了以下四项专属设计原则。

**非具象与音乐可视化**是首要原则。构造体的视觉设计应严格遵循"非具象"和"音乐可视化"的原则，采用全息波形、悬浮的抽象乐器部件或神圣几何体作为设计语言，避免任何传统意义上的生物或机械形态。一个悬浮的、随节拍脉动的发光立方体，比任何具体的"炮台"形象都更能传达"节拍哨塔"的音乐本质。

**节拍同步（Rhythm Sync）**是贯穿所有特效的核心技术要求。所有特效的生命周期——从召唤具现化到最终消散——都必须与全局 BPM 严格对齐。强拍（第1/3拍）与弱拍（第2/4拍）之间的视觉反馈必须有显著差异，使构造体成为战场上"可见的节拍器"，让玩家能够通过视觉感知当前的节拍位置，从而做出更精准的战术决策。

**色彩编码系统**是保证战场可读性的关键手段。通过为三大类构造体（律动塔/共鸣器/干扰场）分配专属的色彩体系，玩家可以在混乱的战场中瞬间识别每个构造体的功能类型，从而快速做出战术判断。

**相位响应**是本系统与频谱相位系统深度整合的体现。构造体的视觉形态需随玩家切换的频谱相位（高通/低通/全频）动态变化，不仅辅助玩家进行战斗解谜，更从视觉上强化了"战斗即混音"的核心体验。

## 2. 视觉色彩编码系统

为了在复杂的弹幕环境中保持高可读性，我们为三大类构造体定义了专属的色彩编码、基础形状语言和材质质感。这一系统的设计灵感来源于专业音频设备中不同功能模块的色彩区分惯例，将其转化为游戏视觉语言。

| 构造体类型 | 构造体成员 | 主色调 | 辅助色调 | 基础形状语言 | 材质质感 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **律动塔 (Rhythm)** | C 节拍哨塔、G 重低音炮 | **谐振青** `#00FFFF` | 亮白色 `#FFFFFF` | 锐利的几何体（立方体、震膜） | 高发光 (Emission)、硬边缘、金属质感 |
| **共鸣器 (Resonance)** | D 长程棱镜、A 和声光环 | **圣光金** `#FFD700` | 琥珀色 `#FFBF00` | 圆润的几何体（三棱镜、莲花） | 玻璃折射、内部流光、温暖光晕 |
| **干扰场 (Modulation)** | E 低频音墙、F 净化信标、B 高频陷阱 | **深邃紫** `#8A2BE2` | 霓虹粉 `#FF10F0` | 扩散的波形、不规则多边形、网格 | 半透明、噪波扭曲、电弧质感 |

**色彩使用规范**：主色调用于构造体的核心本体和主要特效；辅助色调用于能量流动、粒子拖尾和边缘高光。在强拍行动时，辅助色调的比例应大幅提升，以强化视觉冲击力。在弱拍行动时，整体饱和度和亮度应降低约 40%，清晰地传达"效能减半"的状态。

## 3. 7种构造体完整特效链设计

每个构造体的特效链包含五个阶段：**召唤/放置**（具现化过程）、**待机状态**（随 BPM 呼吸的视觉脉冲）、**强拍行动**（100% 效能时的视觉爆发）、**弱拍行动**（50% 效能时的视觉减弱）、**消散/淡出**（生命周期结束时的消散效果）。

### 3.1. C 节拍哨塔 (律动塔)

> **音乐隐喻：稳定的底鼓 (Kick Drum)**  
> **类型：** 律动塔 | **色彩：** 谐振青 `#00FFFF` | **行为：** 每拍向最近敌人发射基础弹体

**召唤/放置动画（时长约 0.5 拍）**

召唤动画的节奏与强拍对齐。玩家放置时，地面首先出现一个青色的正方形能量印记，随后一个线框立方体从印记中心向上拔起，线框的每条棱都带有高亮的流光。在到达最终高度的瞬间，线框内部被实体材质迅速填充，伴随一声沉闷的低频"咚"声，同时向四周释放一圈低矮的青色冲击波，宣告构造体已就位。

**待机状态（持续至消散）**

立方体悬浮在半空中，与地面保持约 0.5 单位的距离，随着 BPM 进行轻微的上下浮动（振幅约 0.1 单位，频率与 BPM 同步）。立方体表面有青色的数据流光自下而上滚动，滚动速度与 BPM 成正比。在每个弱拍时刻，立方体会有一次轻微的亮度脉冲，如同心跳，提示玩家下一个强拍即将到来。

**强拍行动特效（100% 效能）**

在强拍信号到来的瞬间，立方体产生一次剧烈的"蓄力-释放"动画：先在 0.05 拍内迅速收缩至原体积的 70%，随后在 0.1 拍内猛烈膨胀至 130%，同时向最近敌人发射一枚高亮的青色光矢。光矢的核心为纯白色，外层为青色光晕，带有短促的 `TubeTrailMesh` 拖尾。发射瞬间，立方体周围产生一圈锐利的方形冲击波（使用 `ImmediateMesh` 绘制），冲击波在 0.2 拍内向外扩散并消失。

**弱拍行动特效（50% 效能）**

立方体仅产生轻微的形变（收缩至 90%，膨胀至 110%），发射的光矢体积缩小 50%，亮度降低至强拍的 60%，拖尾长度减半，无方形冲击波。整体视觉节奏更为平缓，清晰地传达"效能减半"的状态。

**消散/淡出动画（时长约 1 拍）**

当生命周期结束时，立方体首先产生一次剧烈的抖动（模拟"最后一跳"），随后分解为无数青色的数字碎片（`GPUParticles3D`），碎片向上飘散并逐渐变暗、变小，最终在约 1 拍的时间内完全消失。地面的印记也随之黯淡。

### 3.2. D 长程棱镜 (共鸣器)

> **音乐隐喻：延迟/回声效果器 (Delay)**  
> **类型：** 共鸣器 | **色彩：** 圣光金 `#FFD700` | **行为：** 穿过的弹体射程翻倍并分裂

**召唤/放置动画**

三道金色的光束从天而降，形成三角形的交汇点，在交汇处凝聚成一个悬浮的金色三棱镜。棱镜具现化的过程伴随着折射光的散射效果——彩虹色的光斑在地面上短暂闪烁，如同阳光穿过真实的三棱镜。

**待机状态**

三棱镜以约 0.5 转/拍的速度缓慢自转，内部有金色的光芒流转，如同被封印在其中的能量。随着 BPM，棱镜的三条棱会周期性地闪烁高光，如同三根琴弦在拨动。棱镜底部向地面投射出一个金色的三角形光影，光影的边缘随 BPM 轻微扩张和收缩。

**强拍行动特效（100% 效能）**

当玩家弹体穿过棱镜时，棱镜爆发出耀眼的金色星芒（Lens Flare 效果，通过 `OmniLight3D` 的瞬间能量提升实现），持续约 0.15 拍。穿过的弹体被复制并放大，原弹体射程翻倍，分裂出的弹体以扇形角度向两侧飞出，两者都带有更华丽的金色拖尾。

**弱拍行动特效（50% 效能）**

棱镜的光芒略微黯淡，穿过的弹体仅被复制（无放大效果），分裂角度减小，无明显的星芒爆发。整体效果更为低调。

**消散/淡出动画**

棱镜的折射率逐渐降低，表面的金色流光减慢并消失，棱镜变得完全透明，最后化为一缕金色的光尘消散。消散的过程如同一段音乐的"淡出"（Fade Out），平缓而优雅。

### 3.3. E 低频音墙 (干扰场)

> **音乐隐喻：门限效果器 (Gate)**  
> **类型：** 干扰场 | **色彩：** 深邃紫 `#8A2BE2` | **行为：** 生成阻挡敌人的波形墙，接触时推开

**召唤/放置动画**

地面出现一道细长的紫色裂隙，裂隙沿着玩家指定的方向延伸。随后，一道由密集声波纹理构成的半透明紫色光墙从裂隙中拔地而起，墙体的高度在约 0.5 拍内达到最终值。光墙的表面纹理使用滚动的正弦波 Shader 实现，营造出声波可视化的效果。

**待机状态**

光墙表面呈现出类似示波器的动态波形，波形的振幅随 BPM 呼吸——在强拍时振幅最大，在弱拍时振幅最小。光墙的整体透明度在 60%-80% 之间动态变化，使其既可见又不完全遮挡视线。

**强拍行动特效（100% 效能）**

光墙的波形振幅在强拍时刻达到最大，颜色瞬间从深邃紫变为刺眼的霓虹粉（持续约 0.1 拍），如同门限效果器在强信号下的"开门"状态。接触光墙的敌人被强力推开，接触点爆发出紫色的同心圆涟漪，涟漪向外扩散约 2 单位后消失。

**弱拍行动特效（50% 效能）**

光墙波形平缓，颜色保持深邃紫，推力减弱至 50%，接触点仅产生微弱的紫色火花，无同心圆涟漪。

**消散/淡出动画**

光墙的波形逐渐平息为一条直线，随后像老式电视机关机一样，向中心收缩为一条亮线，最终消失。这一动画精准地隐喻了"门限关闭"的音频概念，与其音乐隐喻高度统一。

### 3.4. F 净化信标 (干扰场)

> **音乐隐喻：降噪器 (De-noiser)**  
> **类型：** 干扰场 | **色彩：** 深邃紫 `#8A2BE2` | **行为：** 范围内每小节清除一个敌人的弹幕或 Debuff

**召唤/放置动画**

一个紫色的倒置圆锥体从虚空中浮现，尖端指向地面，在地面投射出一个复杂的圆形法阵。法阵的图案由内向外逐渐展开，如同一个降噪算法正在初始化。法阵的边缘有紫色的符文依次点亮，伴随一阵清脆的高频音效，宣告信标已就位。

**待机状态**

圆锥体以极缓慢的速度旋转，法阵边缘的符文随 BPM 依次闪烁，形成一圈流动的光环。圆锥体内部有稀疏的紫色粒子向下缓慢飘落，如同降噪滤波器正在持续工作。

**强拍行动特效（100% 效能）**

在每个小节的第一拍（强拍），圆锥体尖端向地面释放一道强烈的紫色光柱，光柱在约 0.2 拍内达到最大亮度，随后在 0.3 拍内消散。法阵范围内爆发出一阵**反向收缩**的粒子流——所有粒子从法阵边缘向中心汇聚，象征着弹幕和 Debuff 被"吸除"。被净化的敌人身上会出现短暂的白色闪光，表示其 Debuff 已被清除。

**弱拍行动特效（50% 效能）**

光柱变细，亮度降低，法阵范围内的粒子流变得稀疏，净化效果减弱（仅清除一个效果而非全部）。

**消散/淡出动画**

圆锥体从底部向上逐渐溶解（使用噪波纹理驱动的 Shader 溶解效果），法阵的光芒也随之从外向内黯淡，最终只剩下中心的一个光点，然后消失。

### 3.5. G 重低音炮 (律动塔)

> **音乐隐喻：贝斯/808鼓 (Sub-Bass)**  
> **类型：** 律动塔 | **色彩：** 谐振青 `#00FFFF` | **行为：** 仅在强拍发射高伤冲击波

**召唤/放置动画**

一个巨大的、由青色能量构成的扬声器震膜在地面上具现化。具现化过程从中心向外扩展，如同一个巨大的圆形涟漪。震膜的边缘有密集的同心圆纹理，中心有一个发光的青色能量核心。周围的空气因低频震动而产生视觉扭曲（使用折射 Shader 实现），营造出强烈的低频存在感。

**待机状态**

震膜随着 BPM 进行深沉的"呼吸"——在强拍时向外微微鼓起，在弱拍时向内微微凹陷，振幅约为震膜半径的 5%。每次呼吸都会在地面产生微弱的青色涟漪，涟漪向外扩散约 3 单位后消失。这种持续的低频视觉脉冲使重低音炮在待机状态下就具有强烈的存在感。

**强拍行动特效（100% 效能）**

在强拍信号到来时，震膜先向内极度凹陷（约 0.1 拍，凹陷深度为震膜半径的 30%），蓄积能量，随后猛烈弹出，释放出一道极具破坏力的青色环形冲击波。冲击波以极快的速度向外扩散，边缘带有空间撕裂效果（通过折射 Shader 实现）。屏幕产生强烈的震动（Camera Shake，持续约 0.3 拍），强化打击感。这是场上视觉冲击力最强的构造体行动之一。

**弱拍行动特效（休止）**

重低音炮在弱拍时**完全休止**，不进行攻击。震膜保持待机状态，但可以观察到能量在核心处缓慢积蓄——核心的亮度在弱拍期间逐渐提升，为下一个强拍的爆发做视觉铺垫。这种"蓄力感"使玩家能够预判强拍时刻，从而配合走位。

**消散/淡出动画**

震膜的能量耗尽，发出一声长长的低频叹息（音效），随后震膜的纹理逐渐模糊，化为一滩青色的液态能量渗入地下，地面留下一个短暂的青色印记后消失。

### 3.6. A 和声光环 (共鸣器)

> **音乐隐喻：铺底音色 (Pad)**  
> **类型：** 共鸣器 | **色彩：** 圣光金 `#FFD700` | **行为：** 范围内玩家的疲劳值缓慢恢复

**召唤/放置动画**

一朵由金色光线编织而成的抽象莲花在半空中绽放。绽放过程从中心向外展开，每片"花瓣"（实为弯曲的光线几何体）依次展开，伴随着和谐的泛音音效。莲花绽放完成时，向四周散发出柔和的金色光晕，光晕的范围即为其治愈效果的覆盖区域。

**待机状态**

莲花以极缓慢的速度缓慢开合，模拟"呼吸"的节奏。光晕的范围随 BPM 轻微扩张（强拍时最大）和收缩（弱拍时最小），营造出一种宁静、治愈的氛围。莲花内部有稀疏的金色粒子缓慢飘落，如同金色的花粉。

**强拍行动特效（100% 效能）**

莲花完全绽放，释放出一阵金色的治愈光雨（`GPUParticles3D`，粒子向下飘落）。落在玩家身上时产生温暖的金色光斑（使用 `Decal` 节点实现），加速疲劳恢复。同时，莲花周围的光晕亮度瞬间提升至 150%，然后在约 0.5 拍内恢复正常，形成一次温暖的"脉冲"。

**弱拍行动特效（50% 效能）**

莲花半闭，光雨变得稀疏，粒子密度降低至 50%，治愈效果减半。光晕亮度无明显变化。

**消散/淡出动画**

莲花的花瓣一片片剥落，化为金色的光点消散在空气中。整个消散过程如同一段音乐的"淡出"，平缓而优雅，与其治愈、宁静的气质高度一致。

---

### 3.7. B 高频陷阱 (干扰场)

> **音乐隐喻：踩镲 (Hi-hats)**  
> **类型：** 干扰场 | **色彩：** 深邃紫 `#8A2BE2` | **行为：** 地面生成尖刺区域，持续造成高频伤害

**召唤/放置动画**

地面上迅速蔓延开一片紫色的几何网格，网格从放置点向外扩展，如同电路板上的电流蔓延。网格的节点上闪烁着锐利的光芒，如同踩镲的金属光泽。整个蔓延过程约 0.3 拍，快速而有力，与踩镲的"嗒"声节奏一致。

**待机状态**

网格上的光芒随 BPM 快速闪烁，如同跳动的电流——在强拍时全亮，在弱拍时半暗，形成快速的明暗交替，如同踩镲的高频节奏。网格表面有细小的紫色电弧在节点之间随机跳动，增强高频、锐利的视觉感受。

**强拍行动特效（100% 效能）**

网格节点上瞬间刺出无数紫色的高频能量尖刺，尖刺的高度约为 0.5 单位，持续约 0.15 拍后收回。对经过的敌人造成高频切割伤害，伴随刺耳的电流声。被命中的敌人身上会出现紫色的高频电弧效果，持续约 0.3 拍。

**弱拍行动特效（50% 效能）**

尖刺的高度减半（约 0.25 单位），闪烁频率降低，伤害减弱至 50%。电弧效果也相应减弱。

**消散/淡出动画**

网格从边缘向中心逐渐断裂、熄灭，如同电路板断电。每条网格线在断裂时产生短暂的紫色火花，最后中心的最后一个节点发出一声短促的"嗒"声后消失，地面留下一片短暂的紫色灰烬。

## 4. 共鸣网络视觉连线效果

共鸣网络是召唤系统的核心策略机制，其视觉表现必须清晰地传达出"连接"、"增益"和"伤害"三种状态。

### 4.1. 音频线缆 (Patch Cable) 的视觉表现

当两个**同类型**构造体之间的距离小于 400 像素时，它们之间会自动生成一条"音频线缆"。线缆的视觉表现采用分层设计：

**基础层**是一条由发光粒子流构成的线段，粒子的颜色与构造体类型一致（律动塔=谐振青，共鸣器=圣光金，干扰场=深邃紫）。粒子流的密度适中，既能清晰可见，又不会过度遮挡战场视线。

**能量脉冲层**是在基础粒子流之上叠加的亮色光团，光团在两个构造体之间来回穿梭，穿梭的速度与 BPM 同步——每个强拍时刻，一个光团从一端出发，在下一个强拍时刻到达另一端，形成规律的能量传输视觉。

**连接状态指示**：线缆的粗细和亮度反映网络的健康状态。当两个构造体都处于正常工作状态时，线缆保持标准粗细和亮度；当某个构造体即将消散时，线缆会开始闪烁，提示玩家及时补充。

### 4.2. 网络激活时的增益视觉反馈

当构造体成功接入共鸣网络时，会产生以下视觉反馈：

**节点共鸣**：构造体底部的法阵图案变得更加复杂，新增一圈旋转的外环，整体亮度提升约 20%。这一变化清晰地告知玩家"此构造体已获得网络增益"。

**全局脉冲**：整个共鸣网络会随着每个强拍产生一次全局的亮度脉冲，所有连接的线缆和构造体在同一瞬间闪耀，持续约 0.1 拍。这一全局同步的视觉效果强化了"协同工作"的感受，使玩家能够直观感受到网络的整体节律。

**几何阵型加成**：当三个或更多同类型构造体形成特定几何阵型（如三角形、矩阵）时，网络中心会出现一个对应的几何图案（如三角形网络出现发光三角形），并产生一次更强烈的全局脉冲，提示玩家已触发阵型加成。

### 4.3. 敌人穿过线缆时的伤害反馈

当敌人穿过音频线缆时，会产生以下视觉反馈：

**切割效果**：线缆在接触点产生剧烈的**电弧火花**（对应颜色的 `GPUParticles3D`），火花向四周飞溅，持续约 0.2 拍。线缆本身在接触点处会短暂断裂，然后迅速重新连接，如同被切断的电路在自我修复。

**受击反馈**：敌人身上会出现短暂的网格状高光闪烁（使用 Hit Flash Shader 实现），颜色与线缆一致，持续约 0.15 拍，表示受到了线缆的切割伤害。

**持续伤害指示**：如果敌人持续停留在线缆上，其身上的网格状高光会持续闪烁，且闪烁频率随 BPM 同步，强化"被音频线缆持续切割"的视觉感受。

## 5. 频谱相位下的形态变化

根据《频谱相位系统设计文档》，构造体在不同频谱相位下将呈现出截然不同的视觉形态，以辅助玩家进行战斗解谜，并强化"战斗即混音"的核心体验。

### 5.1. 相位切换过渡动画

当玩家切换频谱相位时，场上所有构造体会在约 0.5 拍内完成形态过渡。过渡动画使用 Tween 系统平滑插值 Shader 参数，避免生硬的瞬间切换。过渡期间，构造体会短暂呈现出两种形态叠加的"中间态"，如同两种波形在叠加时产生的干涉图样。

### 5.2. 各类型构造体的相位形态

| 构造体类型 | 全频相位 (Fundamental) | 高通相位 (Overtone) | 低通相位 (Sub-Bass) |
| :--- | :--- | :--- | :--- |
| **律动塔 (青色)** | 标准几何体，高发光，硬边缘 | 变为极细的亮青色线框，攻击弹道变为瞬发激光，速度极快 | 变为厚重的暗青色液态球体，攻击变为缓慢的重力波，范围扩大 |
| **共鸣器 (金色)** | 圆润几何体，内部流光，温暖光晕 | 变为刺眼的金色星芒，增益范围扩大，但效果持续时间缩短 | 变为坚固的琥珀色晶体，增益范围缩小，但效果强度提升并提供护盾 |
| **干扰场 (紫色)** | 扩散波形，半透明，噪波纹理 | 变为高频闪烁的紫色噪点云，控制效果变为短暂的强力眩晕 | 变为粘稠的深紫色泥沼，控制效果变为持续的强力减速 |

### 5.3. 特定构造体的相位联动效果

部分构造体在特定相位下会获得额外的视觉增强效果：

**长程棱镜（D）在高通相位**：棱镜的折射效果增强，穿过它的弹体会附加"频谱穿透"的视觉标记（弹体外层出现彩虹色的光晕），表示该弹体能同时伤害所有相位的敌人。

**低频音墙（E）在低通相位**：光墙变得更加厚重，波形振幅增大，颜色从深邃紫变为更深沉的暗红紫色，推力大幅增强，接触点的涟漪效果也更加剧烈。

## 6. 玩家指挥激励特效

当玩家的弹体击中自己的构造体时，会触发"激励"效果，使构造体立即执行一次额外的强拍效果。这一交互需要专属的视觉反馈来传达"激励成功"的信息。

**激励触发瞬间**：弹体击中构造体的瞬间，不产生普通的命中效果，而是产生一个向心收缩的能量球，随后爆发出一圈由构造体颜色构成的同心圆涟漪（半径约 1.5 单位），伴随悦耳的"调音"音效。

**激励执行动画**：构造体立即执行一次强拍行动，但此次行动的视觉效果在标准强拍效果的基础上叠加了一层"金色光晕"，表示这是由玩家主动激励触发的额外行动，与自动触发的强拍行动有所区别。

**反馈强化**：激励成功后，构造体的整体亮度会短暂提升约 30%，持续约 0.5 拍，如同乐手受到指挥家的鼓励后精神焕发，为玩家提供强烈的正向反馈。

## 7. 音色系统对构造体的视觉修饰

玩家当前激活的音色会为所有召唤物附加一层全局的"行为滤镜"。以下是各音色系别对构造体视觉的修饰效果：

| 音色系别 | 视觉修饰效果 | 实现方案 |
| :--- | :--- | :--- |
| **弹拨系** | 构造体攻击时，额外弹射出 2 个微型音符，音符呈金色水滴形，带有弹拨拖尾 | 在攻击时额外生成 2 个小型 `GPUParticles3D` 节点 |

## 8. 技术实现方案 (Godot 4.x)

### 8.1. 构造体基础架构

每个构造体场景的节点结构如下：

```
SummonBase (Node3D)
├── MeshInstance3D (主体几何体)
│   └── ShaderMaterial (动态 Shader，接收 BPM 参数)
├── GPUParticles3D (待机粒子)
├── GPUParticles3D (行动粒子)
├── GPUParticles3D (消散粒子)
├── OmniLight3D (动态发光)
├── CollisionShape3D (碰撞体)
└── Area3D (共鸣网络检测区域)
```

### 8.2. 节拍同步实现

构造体的所有视觉动画通过监听 `MusicTheoryEngine` 的 `beat_signal` 来实现节拍同步：

```gdscript
# summon_vfx_base.gd
extends Node3D

@onready var main_mesh: MeshInstance3D = $MeshInstance3D
@onready var idle_particles: GPUParticles3D = $IdleParticles
@onready var action_particles: GPUParticles3D = $ActionParticles
@onready var point_light: OmniLight3D = $OmniLight3D

var beat_tween: Tween
var shader_material: ShaderMaterial

func _ready():
    shader_material = main_mesh.get_surface_override_material(0)
    MusicTheoryEngine.connect("beat_signal", _on_beat)
    PhaseManager.connect("phase_changed", _on_phase_changed)

func _on_beat(beat_index: int, is_strong_beat: bool):
    # 待机呼吸动画（每拍触发）
    _animate_idle_pulse(is_strong_beat)
    # 行动特效（由子类实现）
    if is_strong_beat:
        _on_strong_beat()
    else:
        _on_weak_beat()

func _animate_idle_pulse(is_strong: bool):
    if beat_tween:
        beat_tween.kill()
    beat_tween = create_tween()
    var target_scale = Vector3(1.1, 1.1, 1.1) if is_strong else Vector3(0.95, 0.95, 0.95)
    var target_emission = 2.0 if is_strong else 1.0
    beat_tween.tween_property(main_mesh, "scale", target_scale, 0.05)\
        .set_trans(Tween.TRANS_EXPO).set_ease(Tween.EASE_OUT)
    beat_tween.tween_property(main_mesh, "scale", Vector3.ONE, 0.15)\
        .set_trans(Tween.TRANS_SINE).set_ease(Tween.EASE_IN_OUT)
    beat_tween.parallel().tween_property(shader_material,
        "shader_parameter/emission_energy", target_emission, 0.05)
    beat_tween.tween_property(shader_material,
        "shader_parameter/emission_energy", 1.0, 0.2)

func _on_phase_changed(new_phase: int):
    # 0=全频, 1=高通, 2=低通
    var phase_tween = create_tween()
    phase_tween.tween_property(shader_material,
        "shader_parameter/phase_blend", float(new_phase), 0.3)\
        .set_trans(Tween.TRANS_SINE)
```

### 8.3. 共鸣网络线缆实现

共鸣网络线缆使用 `ImmediateMesh` 动态绘制，并通过滚动 UV 实现能量脉冲效果：

```gdscript
# resonance_cable.gd
extends MeshInstance3D

var start_node: Node3D
var end_node: Node3D
var cable_material: ShaderMaterial
var uv_offset: float = 0.0

func _process(delta: float):
    _update_cable_mesh()
    uv_offset += delta * (MusicTheoryEngine.bpm / 60.0)
    cable_material.set_shader_parameter("uv_offset", uv_offset)

func _update_cable_mesh():
    var immediate_mesh = ImmediateMesh.new()
    immediate_mesh.surface_begin(Mesh.PRIMITIVE_TRIANGLE_STRIP, cable_material)
    var dir = (end_node.global_position - start_node.global_position).normalized()
    var perp = dir.cross(Vector3.UP).normalized() * 0.05
    # 生成带宽度的四边形条带顶点（此处省略具体顶点生成代码）
    immediate_mesh.surface_end()
    self.mesh = immediate_mesh
```

### 8.4. 相位 Shader 实现

构造体的相位形态变化通过一个统一的 Spatial Shader 实现，通过 `phase_blend` 参数在三种形态之间插值：

```glsl
// summon_phase.gdshader
shader_type spatial;

uniform float phase_blend : hint_range(-1.0, 1.0) = 0.0; // -1=低通, 0=全频, 1=高通
uniform float emission_energy : hint_range(0.0, 5.0) = 1.0;
uniform vec4 base_color : source_color = vec4(0.0, 1.0, 1.0, 1.0);
uniform sampler2D noise_texture;

void fragment() {
    float noise = texture(noise_texture, UV + vec2(TIME * 0.1, 0.0)).r;
    float wireframe_strength = max(0.0, phase_blend);
    float liquify_strength = max(0.0, -phase_blend);
    vec3 final_color = base_color.rgb;
    // 高通：颜色变亮，边缘锐化
    final_color = mix(final_color, vec3(1.0), wireframe_strength * 0.5);
    // 低通：颜色变暗，增加噪波扭曲
    final_color = mix(final_color, final_color * 0.5 + vec3(0.1, 0.0, 0.2),
        liquify_strength * 0.7);
    ALBEDO = final_color;
    EMISSION = final_color * emission_energy;
    ALPHA = mix(1.0, 0.6 + noise * 0.4, liquify_strength);
}
```

### 8.5. 性能优化策略

鉴于战场上最多同时存在多个构造体以及共鸣网络线缆的动态绘制，需要注意以下性能优化策略：

**粒子预热**：所有构造体的 `GPUParticles3D` 节点在场景加载时进行预热（`preprocess` 设为 1.0），避免首次激活时的卡顿。

**线缆绘制优化**：共鸣网络线缆使用 `ImmediateMesh` 而非 `GPUParticles3D` 实现，以减少粒子系统的开销。线缆的更新频率可降低至每 2 帧一次（约 30fps 更新），玩家几乎无法察觉差异。

**Shader 参数批量更新**：当相位切换时，通过全局的 `PhaseManager` 单例批量更新所有构造体的 Shader 参数，而非逐个更新，减少 CPU 到 GPU 的通信开销。
