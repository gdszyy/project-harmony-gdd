# 第七章 Boss (boss_noise.gd) 修正与波次补充报告

## 1. 任务概述

本报告记录了针对《Project Harmony》第七章最终Boss（合成主脑·噪音）代码 `boss_noise.gd` 的修正工作，以及针对第2至第7章缺失波次数据文件的补充工作。所有修改均严格遵循《关卡与Boss整合设计文档_v3.0.md》的详细设计要求。

## 2. boss_noise.gd 修正详情

### 2.1 频谱相位系统对应关系
- **修改前**：Boss 的四种波形攻击对玩家无差别造成伤害。
- **修改后**：在弹幕生成和移动逻辑中引入了对玩家当前相位的检测。
  - **正弦波**：仅在玩家处于**低通相位 (1)** 或 **全频相位 (3)** 时生效，若玩家处于高通相位则弹幕半透明且无伤害。
  - **锯齿波**：仅在玩家处于**高通相位 (2)** 或 **全频相位 (3)** 时生效。
  - **方波**：仅在玩家处于**全频相位 (3)** 时生效。
  - **白噪音**：全相位生效，无法通过切换相位免疫。

### 2.2 频谱崩溃最终阶段
- **修改前**：Boss HP 降至 0 时直接死亡。
- **修改后**：引入了 `SPECTRUM_COLLAPSE_THRESHOLD` (10%)。当 Boss HP < 10% 时，触发**频谱崩溃**状态。
  - Boss 停止常规移动和阶段切换。
  - 视觉上呈现全屏故障和剧烈的颜色变换。
  - 疯狂且同时释放所有四种波形的弹幕。
  - 在此阶段，Boss 对普通攻击免疫，只能被终结技能击杀。

### 2.3 终结机制（减十三和弦）
- **新增机制**：添加了 `cast_final_chord()` 方法供外部 Game Manager 调用。
- **逻辑实现**：玩家在频谱崩溃阶段释放"终焉乐章"（减十三和弦）后，会有 **4 拍的延迟**（`FINAL_CHORD_DELAY = 4.0`）。延迟结束后触发 `_execute_final_blow()`，强制击杀 Boss。

### 2.4 取消风格排斥
- **修改前**：存在"单一的诅咒"系统，如果玩家连续使用同一种音色攻击，Boss 会产生免疫。
- **修改后**：根据设计文档，最终战允许任何策略。已彻底移除了 `MONOTONE_THRESHOLD` 及其相关的免疫计时器、视觉反馈和伤害减免逻辑。

### 2.5 数值调整
- **HP 修正**：将 Boss 的 `max_hp` 和 `current_hp` 从 7000 修正为 10000，以符合最终 Boss 的难度定位。
