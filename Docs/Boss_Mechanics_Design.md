# Project Harmony - Boss核心战斗机制设计文档

本文档详细说明了Project Harmony中4个待完善Boss（圭多、巴赫、莫扎特、爵士）的核心战斗机制、阶段转换、专属技能以及视觉效果方案。

## 1. 圣咏宗师·圭多 (Guido) - 第二章Boss
**核心理念**: 中世纪单声部圣咏的化身，强调"齐唱"的压迫感，惩罚玩家对单音的过度依赖。
**时代特征**: 【神圣齐唱】——周期性出现圣咏轨迹，敌人排列其上同步发射直线弹幕。
**风格排斥**: 【独声的傲慢】——10秒内只用单音攻击则触发"声部孤立"Debuff。

### 1.1 阶段设计
* **阶段一：齐唱之墙 (100% - 60% HP)**
  * **圣咏轨迹**: 每16拍出现一条水平发光轨迹，6只Static被吸附其上排成一列，同步发射缓慢直线弹幕形成"音墙"。
  * **圣歌护盾**: Boss本体被"圣歌护盾"保护，只有在圣咏轨迹上的所有Static被清除后，护盾才会短暂消失4秒。
  * **声部孤立检测**: Boss持续监测玩家的攻击类型。如果10秒内只使用单音，触发Debuff（治疗和护盾效果降低50%）。
* **阶段二：双声部圣咏 (60% - 0% HP)**
  * **双轨迹**: 同时出现两条圣咏轨迹（上下平行），形成双层音墙。
  * **Silence加入**: 1只Silence出现在两条轨迹之间，其静音光环覆盖了最安全的走位区域。
  * **圣咏加速**: Boss HP低于30%时，圣咏轨迹的出现频率从每16拍变为每12拍。

### 1.2 专属视觉效果方案
* **基础外观**: 身着修士长袍的漂浮幽魂，手捧巨大发光乐谱，色调以神圣的金色和纯白色为主。
* **圣咏轨迹**: 轨迹呈现为金色的五线谱线条，被吸附的Static会变成发光的音符形状。
* **圣歌护盾**: 环绕Boss的球形金色护盾，表面有中世纪纽姆记谱法的符号流转。
* **声部孤立惩罚**: 触发时屏幕边缘出现灰暗的羊皮纸纹理，玩家角色身上出现锁链特效。

## 2. 大构建师·巴赫 (Bach) - 第三章Boss
**核心理念**: 复调音乐的终极建筑师，一个由齿轮、管风琴管道和数学公式构成的巨大机械体。
**时代特征**: 【赋格引擎】——Boss释放一条"主题弹幕"后，会在不同位置、不同时间释放该主题的"模仿"（应答、逆行、倒影）。
**风格排斥**: 【单音的贫乏】——连续只用单音攻击时，Boss召唤"音墙"吸收单音并恢复护盾。

### 2.1 阶段设计
* **阶段一：创意/二声部赋格 (100% - 55% HP)**
  * **主题-答题**: Boss释放第一条弹幕轨迹（主题），4拍后第二条轨迹（答题）以不同位置复制第一条的路径。
  * **齿轮弹幕**: 释放旋转的齿轮形弹幕，覆盖大范围区域。
  * **音墙召唤**: 连续单音攻击惩罚，召唤管风琴管组成的音墙吸收单音并恢复护盾。
* **阶段二：赋格/四声部赋格 (55% - 20% HP)**
  * **四声部叠加**: 弹幕轨迹增至4条，每条间隔2拍依次出现，形成极其复杂的弹幕网络。
  * **对位爬虫召唤**: Boss定期召唤对位爬虫作为"伴奏声部"。
  * **管风琴冲击**: 定向高伤害光柱，需要提前预判躲避。
* **阶段三：恰空/终焉赋格 (20% - 0% HP)**
  * **恰空固定低音**: 稳定的环形弹幕作为低音基础，上方声部弹幕逐渐增加复杂度。
  * **终极加速**: 所有赋格轨迹同时激活且速度提升。

### 2.2 专属视觉效果方案
* **基础外观**: 与巨大管风琴融为一体的机械巨像，四只手臂不断操作齿轮和键盘，色调以黄铜色、木质棕色为主。
* **赋格弹幕**: 主题弹幕为明亮的橙色，后续的模仿声部颜色逐渐变深（如深橙、棕红），形状带有齿轮或音符的几何特征。
* **管风琴冲击**: 释放前有强烈的蒸汽喷发和琴管共鸣的视觉预警，光柱呈现出耀眼的金黄色，带有机械纹理。
* **恰空阶段**: 场地背景变为巨大的旋转齿轮盘，随着音乐节拍精确转动。

## 3. 古典完形·莫扎特 (Mozart) - 第四章Boss
**核心理念**: 古典主义完美形式的化身，穿着华丽燕尾服、动作精准优雅的贵公子。
**时代特征**: 【奏鸣曲式力场】——整场Boss战被严格划分为奏鸣曲三部分：呈示部、发展部、再现部。
**风格排斥**: 【繁复的诅咒】——清除过多召唤物并增加疲劳，惩罚缺乏"呼吸感"的战斗方式。

### 3.1 阶段设计
* **阶段一：呈示部 (100% - 55% HP)**
  * **主题A（冲刺斩击）**: Boss进行快速直线冲刺斩击，每次之间有固定节拍间隔。
  * **主题B（圆舞曲弹幕）**: Boss旋转释放螺旋形弹幕，弹幕沿3/4拍节奏扩散。
  * **优雅反击**: 受到特定攻击时释放的反击弹幕。
* **阶段二：发展部 (55% - 20% HP)**
  * **主题变形**: Boss将主题A和B组合，在释放螺旋弹幕的同时进行冲刺斩击。
  * **镜像攻击**: 场景中的镜子边界会反射Boss的弹幕，形成对称的双重威胁。
  * **繁复检测**: 周期性检测玩家的召唤物数量，过多则触发"繁复诅咒"清除召唤物并增加疲劳。
* **阶段三：再现部 (20% - 0% HP)**
  * **华彩乐章**: 主题A和B的速度、范围、伤害全面提升，快速连续冲刺配合密集弹幕。
  * **完美终止**: 终极压迫，要求玩家在极高压力下输出。

### 3.2 专属视觉效果方案
* **基础外观**: 穿着华丽白色燕尾服的贵公子，手持发光的水晶指挥棒，动作如同击剑般优雅，色调以纯白、淡金和水晶蓝为主。
* **冲刺斩击**: 冲刺路径上留下华丽的金色剑痕和星光粒子，动作干脆利落。
* **圆舞曲弹幕**: 弹幕呈现出对称的双螺旋结构，如同宫廷舞会的旋转裙摆。
* **镜像边界**: 场地边缘出现华丽的洛可可风格镜框，弹幕触碰时产生水晶碎裂的反射特效。

## 4. 切分行者·爵士 (Jazz) - 第六章Boss
**核心理念**: 戴着软呢帽、吹着萨克斯的神秘剪影，代表爵士乐的自由、即兴与不可预测性。
**时代特征**: 【摇摆力场】——战场节拍系统转换为摇摆节奏，地面安全区随爵士鼓镲声随机闪现。
**风格排斥**: 【正拍的平庸】——玩家在正拍释放技能时Boss免疫伤害，并用属七和弦炸弹反击。

### 4.1 阶段设计
* **阶段一：即兴前奏 (100% - 55% HP)**
  * **萨克斯音波**: 向玩家方向释放扇形音波弹幕。
  * **摇摆连射**: 以摇摆节奏（长-短-长-短）发射弹幕。
  * **Call & Response**: Boss发出一段节奏"呼叫"弹幕，玩家需要在反拍回应，否则触发惩罚。
* **阶段二：蓝调独奏 (55% - 20% HP)**
  * **行走贝斯线**: 在地面留下伤害轨迹，模拟行走贝斯的音阶进行。
  * **蓝调音阶**: 沿蓝调音阶发射带有"蓝色音符"色彩的弹幕。
  * **聚光灯安全区**: 场地中出现随机移动的聚光灯，作为躲避全屏攻击的安全区。
* **阶段三：自由爵士 (20% - 0% HP)**
  * **自由即兴**: 完全随机的弹幕模式和瞬移，模拟自由爵士的不可预测性。
  * **极限摇摆**: 移动速度和攻击频率大幅提升。

### 4.2 专属视觉效果方案
* **基础外观**: 霓虹灯光背景下的黑色剪影，戴着软呢帽，手持金色的萨克斯风。色调以深紫、霓虹蓝和暗红为主。
* **萨克斯音波**: 弹幕呈现为扭曲的波浪线，带有霓虹发光效果。
* **正拍惩罚**: 触发时Boss化为一团烟雾（虚无状态），并在玩家脚下生成由7个音符组成的橙红色属七和弦炸弹。
* **聚光灯安全区**: 经典的舞台聚光灯效果，打在昏暗的地面上，光柱内有灰尘飞舞的粒子效果。
