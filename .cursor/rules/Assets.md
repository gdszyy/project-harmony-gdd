# Assets 模块规范

## 1. 模块职责

`Assets/` 存放 Project Harmony 的核心视觉概念图、GDD 引用图片、系统示意图和部分文档配图。该模块主要服务于设计表达与文档呈现，不等同于 Godot 运行时资源目录。Godot 实际运行资源应优先查看 `godot_project/assets/` 或场景资源引用。

| 资产类型 | 代表路径 | 使用规则 |
|---|---|---|
| GDD 图表 | `Assets/*.png` | 修改或重命名后必须同步更新 `GDD.md` 引用。 |
| 专项文档图 | `Docs/diagrams/` | 与对应 `Docs/` 文档共同维护。 |
| 概念图 | `Assets/` | 可用于设计说明，不应直接假定已接入游戏运行时。 |
| Godot 资源 | `godot_project/assets/` | 运行时资源以 Godot 场景和脚本引用为准。 |

## 2. 路径一致性

任何图片重命名、移动或替换都必须全仓搜索 Markdown 引用与 Godot 资源引用。设计文档引用通常使用相对路径，必须确保在 GitHub 和本地 Markdown 预览中可解析。

## 3. 编辑规则

新增图表时，应同时说明图表用途、关联设计文档和生成来源。替换图片时，应保留语义一致的文件名，或同步更新所有引用。若图片由脚本或 Mermaid 生成，应优先保留源文件。

## 4. 禁止行为

不得删除仍被 `GDD.md` 或 `Docs/` 引用的图片。不得把低清临时草图覆盖正式图表。不得将运行时资源与文档概念图混用。不得把含敏感信息的截图提交到资产目录。
