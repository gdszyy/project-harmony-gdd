# BalanceKit 模块规范

## 1. 模块职责

`BalanceKit/` 是 Project Harmony 的数值平衡与策略评估工具集，负责对音符、和弦、节奏、升级、疲劳或策略组合进行可解释的评分、模拟和报告输出。该目录为设计与调参服务，不是 Godot 运行时源码。

| 子域 | 代表文件或目录 | 职责 |
|---|---|---|
| 方法论 | `BalanceKit/Methodology.md` | 说明评分框架、指标定义和假设边界。 |
| 跑分脚本 | `BalanceKit/balance_scorer.py` | 计算策略、构筑或参数组合得分。 |
| 报告生成 | `BalanceKit/generate_report.py` | 将平衡分析输出为可阅读报告。 |
| 报告沉淀 | `BalanceKit/Reports/` | 保存已生成的数值分析报告。 |

## 2. 数值变更契约

修改平衡算法、权重、指标或默认参数时，应同步更新方法论文档，并说明变更动机、影响范围和回归比较。若平衡结论影响游戏实现，应同步更新 `godot_project/TODO.md`、相关 `Docs/` 和 Godot 数据源。

| 操作 | 必做项 |
|---|---|
| 修改评分公式 | 更新 `Methodology.md`，记录旧公式与新公式差异。 |
| 新增指标 | 定义单位、取值范围、归一化方式和解释含义。 |
| 生成新报告 | 说明输入数据、运行命令、输出路径和适用版本。 |
| 调整游戏参数 | 检查 Godot 数据、设计文档和 TODO 是否需要同步。 |

## 3. 禁止行为

不得只改跑分脚本而不改方法论说明。不得提交无法复现来源的数据结果。不得将报告结论直接写成实现状态。不得在报告中混入用户私有数据或敏感路径。
