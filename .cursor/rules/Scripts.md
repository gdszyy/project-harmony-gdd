# Scripts 模块规范

## 1. 模块职责

`Scripts/` 存放用于机制验证、数学模型推演和原型计算的辅助脚本。当前重点文件包括 `Scripts/aesthetic_fatigue_system.py`，用于听感疲劳系统的模型表达、指标计算或实验性验证。该目录不是 Godot 运行时代码，不能直接代表游戏内实现状态。

| 脚本类型 | 用途 | 同步要求 |
|---|---|---|
| 模型原型 | 推演 AFI、疲劳维度、平衡参数 | 若结论被采纳，应同步到 `GDD.md`、`Docs/` 或 Godot 实现。 |
| 计算工具 | 临时分析、数据生成、表格输出 | 需要注明输入、输出和复现实例。 |
| 验证脚本 | 验证设计公式或边界条件 | 结果不能替代 `godot_project/TODO.md` 的实现状态。 |

## 2. 编辑规则

脚本应保持可复现，避免依赖本地绝对路径。若脚本输出被文档引用，应保留生成步骤和输出文件位置。涉及听感疲劳或数值模型的变更，应同时检查 `BalanceKit/`、`Docs/` 与 Godot 实现是否需要同步。

## 3. 禁止行为

不得把 Python 原型结果直接视为 Godot 运行时事实。不得提交本地环境路径、私有数据或不可复现的临时文件。不得在没有说明公式来源和参数含义的情况下修改核心计算逻辑。
