# 音符法术特效组合设计方案

**作者：** Manus AI (协调者)
**日期：** 2026-03-06

## 1. 概述

本方案基于对 Godot 3D 特效开发能力、3D 游戏特效设计核心理念以及《Project Harmony》项目 GDD 需求的综合调研，提出了一套针对“音符法术”的特效组合设计方案。该方案旨在将音乐理论（音符、和弦、音色）与视觉特效深度融合，在 2.5D 视角下实现高可读性、强节奏感和独特美学风格的视觉反馈。

## 2. 设计理念与核心原则

在《Project Harmony》的特效设计中，我们遵循以下核心原则：

*   **通感（Synesthesia）与节拍同步：** 特效不仅是视觉反馈，更是“可视化的音乐”。所有核心特效的生命周期（预兆、爆发、持续、消散）必须与音乐节拍（BPM）严格对齐。例如，法术的蓄力应在弱拍进行，爆发必须卡在强拍上。
*   **可读性优先：** 在复杂的弹幕和特效交织中，必须通过清晰的形状语言和色彩编码（Color Coding）确保玩家能瞬间识别法术的层级、属性和危险程度。
*   **模块化与组合性：** 鉴于法术是由基础音符、修饰符和和弦动态组合而成，特效系统也必须是高度模块化的。基础形态、材质滤镜（音色）和附加效果（修饰符）应能无缝叠加。
*   **视觉降级与噪声控制：** 引入特效优先级系统，在同屏特效过多或玩家处于“听感疲劳”状态时，通过缩短消散时间、降低粒子发射率或应用“故障艺术”滤镜来控制视觉噪声。

## 3. Godot 3D 特效技术选型

基于 Godot 4.x 的能力，我们采用以下技术路线来实现音符法术特效：

| 技术方案 | 应用场景 | 性能与实现考量 |
| :--- | :--- | :--- |
| **GPUParticles3D** | 核心法术弹体、爆炸、持续性魔法阵、拖尾（RibbonTrailMesh）。 | 性能极高，支持数十万粒子。利用 `GPUParticlesCollisionSDF3D` 实现与环境的复杂交互。 |
| **Spatial Shader (顶点/片段)** | 弹体材质的动态变化（如水墨波纹、能量丝线）、溶解消散效果、受击闪烁。 | 通过代码动态修改 Shader 参数（如 `dissolve_amount`）来实现平滑过渡。避免复杂的数学运算。 |
| **Tween 系统** | 控制特效的生命周期节奏，如平滑插值发光强度、缩放比例，实现精准的节拍同步。 | 性能开销极低，适合大量并发的程序化动画控制。 |
| **Environment 后处理** | 全局氛围控制（Glow/Bloom）、节拍驱动的全局视觉脉冲、疲劳状态下的色彩偏移。 | 需注意 SSAO 和体积雾的性能开销，合理控制 Glow 的混合模式。 |
| **自定义全屏 Shader** | 实现“单音寂静”的去饱和、“噪音过载”的像素化/色块分离等故障艺术效果。 | 通过 `CanvasLayer` 下的 `ColorRect` 读取 `screen_texture` 实现。 |

## 4. 音符法术特效组合设计

### 4.1. 基础音符（层级 1.5）的视觉分化

基础音符决定了弹体的物理属性，其特效设计应侧重于形态和拖尾的差异化：

*   **巨型缓行弹体（如 E 音符）：** 表现为大范围半透明能量球，内部有缓慢旋转的噪波纹理。使用 `GPUParticles3D` 生成厚重、宽大的粒子拖尾。
*   **高伤快消弹体（如 G 音符）：** 表现为细小但极高亮度的能量奇点（高 Emission 值）。拖尾极短但明亮，命中时产生尖锐的星形闪光。
*   **极速远程弹体（如 D 音符）：** 表现为细长的光矢。使用 `TubeTrailMesh` 生成具有 3D 体积感的流线型拖尾。

### 4.2. 音色（Timbre）系统的视觉滤镜

音色作为“行为滤镜”叠加在基础弹体之上，通过修改 Shader 材质和附加特定粒子来实现：

*   **弹拨系：** 在基础弹体 Shader 上叠加水墨波纹或金色光珠的滚动纹理。命中时，触发一个基于 `Tween` 缩放的同心圆环形 Mesh，模拟声波扩散。
*   **拉弦系：** 弹体由两股缠绕的能量丝线构成（通过顶点 Shader 扭曲实现）。命中后，在目标身上留下发光的共振标记（Decal 或特定 Shader Pass）。
*   **吹奏系：** 弹体边缘柔和，呈半透明气流状。穿透敌人时，发射短暂的竹叶或风旋形状的 CPU 粒子。
*   **打击系：** 弹体形态规整（如立方体）。强拍命中时，触发强烈的屏幕震动（Camera Shake）和基于 Voronoi 算法的碎片飞溅粒子。

### 4.3. 黑键修饰符（层级 1）的瞬时反馈

修饰符提供瞬时的战术优势，其特效必须极具预示性：

*   **穿透：** 弹体前端附加青色激光指示器（细长的锥形 Mesh，高发光）。
*   **追踪：** 弹体周围环绕蓝色的数据流粒子，目标身上出现动态锁定的准星 UI。
*   **分裂：** 弹体核心呈现不稳定的闪烁状态，表面有电弧缠绕（通过快速滚动的噪波纹理实现）。

### 4.4. 和弦法术（层级 2）的形态质变

和弦代表了法术的进阶形态，需要全新的视觉语言：

*   **大三和弦（强化弹体）：** 基础弹体被圣光金色的六边形能量网格包裹（通过 Shader 的 UV 缩放和阈值控制实现）。
*   **减七和弦（天降打击）：** 预兆阶段地面出现血红色预警法阵（`SpotLight3D` 投影纹理）。爆发瞬间，垂直的圆柱体 Mesh 快速缩放落下，伴随全屏短暂闪白（通过控制 Environment 的 Glow 强度）和强烈震动。
*   **挂留和弦（蓄力弹体）：** 蓄力阶段，周围空间产生扭曲（使用读取 `screen_texture` 的折射 Shader），能量粒子呈向心运动被吸入中心的银白色球体。

### 4.5. 疲劳与共鸣切割的全局重塑

*   **听感疲劳（故障艺术）：** 当玩家陷入疲劳时，法术特效发生“数字衰变”。例如，弹体颜色逐渐去饱和变灰，拖尾出现断层，命中特效从平滑的粒子变为方形的马赛克色块。
*   **共鸣切割（相位切换）：** 切换到高通相位时，通过全屏 Shader 将画面线框化，色调转冷，所有法术弹体变亮变细；切换到低通相位时，画面液态化，色调转暖，法术弹体变厚重。这种全局视觉重塑需要与音频的滤波效果绝对同步。

## 5. 总结

本方案通过将 Godot 4.x 的强大 3D 渲染能力（GPUParticles3D、Spatial Shader、Tween）与音乐节奏游戏的通感设计理念相结合，为《Project Harmony》构建了一套模块化、高可读性且极具视觉冲击力的音符法术特效系统。该系统不仅能准确传达复杂的战斗逻辑，还能在视觉上完美契合游戏的“抽象矢量主义 vs. 数字衰变”美学。
